## 归档性能基准

使用同一个 `output.zip`，大小 **393,798,587 字节**（约 376 MiB）。实测日期为 2026-10-03，测量实现对应开发版 0.1.1，后续显示调整与 v1.0.0 发布未改变传输实现。

| 指标 | 结果 |
| --- | ---: |
| 命令行本机 scp | 55.098 秒 |
| 插件核心 scp 阶段 | 54.919 秒 |
| 插件核心总耗时 | 56.063 秒 |
| 准备／校验／提交 | 0.576／0.567／0.000 秒 |
| 核心总耗时 ÷ 同轮命令行耗时 | 101.75% |
| 115% 验收阈值 | 63.363 秒 |

本轮核心耗时满足差距不超过 15% 的目标。用户此前的原生 scp 为 69 秒；网络条件会变化，结论以相邻两次下载对比为准。此次测量不证明此前性能差距的唯一原因。

两次使用同一个 Windows scp 和非交互密钥认证（`BatchMode=yes`），原生下载先执行，插件随后执行。插件测量包含实际 `TransferEngine`、`runScp`、每秒本机文件大小采样、大小校验与重命名。远端元数据用 SSH `stat` 代替 `vscode.workspace.fs`。状态／进度更新 57 次，100 ms 定时器最大额外延迟 15 ms；未测量实际编辑和终端操作。

原始数值保存在 `docs/validation/benchmark.json`，不包含服务器地址或认证信息。

## 实际窗口确认

更新后重新加载 Remote-SSH 窗口。上传／下载各一次，按需确认覆盖、取消与重试；如需速度验收，以同一文件、相近网络条件比较命令行与窗口总耗时，并在传输中继续编辑和操作终端。详细分段耗时在任务日志中。
